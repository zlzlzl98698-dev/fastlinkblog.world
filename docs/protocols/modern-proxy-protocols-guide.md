```
+-------------------------------------------------------------+
|                      代理协议演进历程                         |
|                                                             |
|  Shadowsocks (2012) ──▶ VMess (2016) ──▶ Trojan (2018)     |
|                               │                             |
|                               └──▶ VLESS Reality (2022+)    |
|                                                             |
|  QUIC / UDP 路线 ──────────────────────▶ Hysteria 2 / TUIC  |
+-------------------------------------------------------------+
```

| 协议名称 | 底层传输协议 | 核心加密与伪装机制 | 客户端性能开销 | 核心优势 | 适用典型场景 |
|:---|:---:|:---|:---:|:---|:---|
| **VLESS** | TCP / gRPC | 轻量无状态，无二次繁重加密，可搭配 XTLS / Reality | 极低 | 吞吐上限极高，握手开销低，专线跑满 2.5G | 现代优质 IEPL 专线机场（如光速云） |
| **Shadowsocks** | TCP / UDP | AEAD 对称加密 (AES-128/256-GCM, 2022 Blake3) | 较低 | 协议生态极其成熟，全平台客户端 100% 兼容 | 经典专线中转机场主力协议 |

## 二、VLESS XTLS Reality 为何成为现代主流标配？

传统的 Trojan 与 VMess TLS 方案存在一个痛点：必须由服务商自己购买一个真实域名并申请合法 SSL/TLS 证书。一旦该域名被监管机构列入黑名单，整个机场的节点将全军覆没。

**VLESS Reality** 打破了这种限制：
- **借壳偷天（Borrowing SNI）**：客户端不再连接机场自己的域名，而是在 TLS Client Hello 握手包中填写一个大型合法跨国企业网站的域名（例如 `www.apple.com` 或 `www.microsoft.com`）。
- **特征一致性**：防火墙在外部审查时，看到的完全是客户端与苹果或微软真实服务器之间的合法 TLS 1.3 握手流程，证书链完全真实有效，审查系统无法在握手阶段将其与正常流量区分开来。

## 三、Shadowsocks 2022 规范与专线机场的默契配合

尽管 VLESS 势头强劲，但 **Shadowsocks** 依然是 42 家机场品牌库中占比最高的协议：
- **生态兼容性无可匹敌**：不论是十几年前的老款路由器固件，还是最新的 iOS 软件，都 100% 内置 Shadowsocks 解密模块。
- **专线内的轻装前行**：在物理隔离的 IEPL 专线中，公网防火墙根本接触不到数据包。因此，Shadowsocks 的简单高效成为了专线快速转发数据的极佳载体。

## 四、Hysteria 2 与 TUIC：恶劣高丢包网络下的狂暴利器

基于传统 TCP 协议的代理，最大的弱点是**害怕丢包**。在 TCP 拥塞控制机制中，一旦发生丢包，发送端会强行将滑动窗口减半，导致网速瞬间雪崩。

Hysteria 2 基于 UDP 协议重新设计了拥塞控制算法：
- **激进重传机制**：它不在乎单包的偶然丢失，而是以设定的目标速率高频推送数据包，并通过快速重传弥补损失；
- **劣势与局限**：部分中国电信和中国移动省份的宽带运营商会对公网 UDP 流量实施严格的 QoS 限速与端口惩罚，可能导致连接出现几分钟的短暂阻断。

## 五、系统化网络故障排错树：超时、断连与订阅更新失败

当遇到“节点全部超时”、“订阅更新失败”或“连上代理打不开网页”时，请按照以下诊断流程排查：

```mermaid
flowchart TD
    Issue[遇到网络出海故障] --> Step1{故障现象是什么?}
    
    Step1 -->|订阅更新报错 500/403/无法解析| FixSub[1. 检查官网公告是否更换订阅域名\n2. 关闭已有代理软件后再尝试更新\n3. 检查官网账户是否欠费或到期]
    
    Step1 -->|节点测速全红/Timeout 超时| FixNodes[1. 检查系统时间与互联网时间误差是否超过60秒\n2. 切换手机 5G 热点排查是否为本地局域网限制\n3. 检查是否开启了杀毒软件的流量拦截]
    
    Step1 -->|节点显示绿灯但打不开网页| FixWeb[1. 检查系统代理开关是否开启\n2. 检查 DNS 是否被污染 (在软件内开启 DoH 安全解析)\n3. 尝试开启 TUN 虚拟网卡模式接管全局]
    
    Step1 -->|国内网站变慢或打不开| FixChina[1. 模式必须设为 Rule 规则分流，严禁使用 Global 全局\n2. 检查绕过大陆白名单配置是否完整]
```

### 1. 系统时间误差问题（最常见隐形故障）
如果电脑或手机的时间与北京时间相差超过 60 秒，某些时间敏感的加密握手会被服务器强行拒绝。解决办法：进入系统设置，打开“自动同步时间”并点击立即同步。

### 2. DNS 污染与泄漏排查
许多国内运营商的默认递归 DNS 会将境外被封锁域名的解析结果恶意定向至 `127.0.0.1`。解决办法：在 Clash Verge Rev 中开启【DNS 覆写】，并将 Remote DNS 设置为安全加密的 `https://1.1.1.1/dns-query` (Cloudflare) 或 `https://8.8.8.8/dns-query` (Google)。
