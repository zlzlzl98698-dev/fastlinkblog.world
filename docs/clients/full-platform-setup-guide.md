## 一、Windows 电脑端客户端选型与配置

| 客户端名称 | 核心内核 | 特点与定位 | 官方开源地址 | 飞鸟推荐度 |
|:---|:---|:---|:---|:---:|
| **Clash Verge Rev** | Mihomo (Meta) | 现代跨平台 GUI、支持 TUN 虚拟网卡接管、智能分流、配置覆写脚本 | [GitHub 官方项目](https://github.com/clash-verge-rev/clash-verge-rev) | ★★★★★ |
| **v2rayN** | Xray / sing-box | 经典老牌、支持全协议多节点批量测速、路由高级规则设置 | [GitHub 官方项目](https://github.com/2dust/v2rayN) | ★★★★★ |
| **FlClash** | Mihomo | 基于 Flutter 构建、界面极其精致清爽、内存开销低 | [GitHub 官方项目](https://github.com/chen08209/FlClash) | ★★★★☆ |
| **Hiddify** | sing-box | 全协议支持、一键式傻瓜连接、自动选优节点 | [GitHub 官方项目](https://github.com/hiddify/hiddify-next) | ★★★★☆ |

### Clash Verge Rev Windows 快速上手四步法：
1. **下载安装**：前往 GitHub Releases 下载带有 `x64-setup.exe` 的官方安装包完成安装；
2. **导入订阅**：点击左侧【订阅】页面，粘贴从光速云或飞猫云后台复制的 Clash 订阅链接，点击【保存并更新】；
3. **选择节点**：切换至【代理】页面，模式选择 **Rule（规则分流）**，点击测速后选择延迟最低的专线节点（如香港 IEPL 01）；
4. **启动连接**：切换回【设置】页面，勾选【系统代理】或开启【TUN 模式】即可开启全局出海。

## 二、macOS 苹果电脑端客户端配置实操

在 Mac 电脑上使用代理软件，最重要的是区分芯片架构：
- **Apple Silicon (M1/M2/M3/M4)**：请务必下载 `aarch64 / arm64.dmg` 版本，原生运行零转译性能损耗，功耗极低；
- **Intel 处理器（旧款 Mac）**：请下载 `x64.dmg` 版本。

推荐首选 **Clash Verge Rev (Mac 版)**，其内置的系统级守护进程能完美接管 Terminal 终端与各类本地 IDE 开发环境的出海流量。

## 三、iOS 苹果手机端客户端与美区 Apple ID 获取

由于政策限制，中国大陆地区的 App Store 无法上架网络代理类软件。iOS 用户出海必须准备一个**外区 Apple ID（如美区、日区、港区）**。

| 客户端名称 | App Store 属性 | 核心优势 | 适用人群 |
|:---|:---:|:---|:---|
| **Shadowrocket (小火箭)** | 付费 ($2.99) | 上手简单、支持二维码扫码导入、节点测速快捷、耗电低 | 绝大多数 iOS 用户首选 |
| **Stash** | 付费 ($3.99) | 完美兼容 Clash YAML 语法与策略组分流、UI 现代精致 | 追求高级规则与策略组用户 |
| **Quantumult X (圈 X)** | 付费 ($7.99) | 脚本重写功能极强、分流规则精细、适合高阶玩家 | 极客与去广告脚本玩家 |

::: warning ⚠️ 安全警示
切勿在 iPhone 的【设置 > iCloud】中登录陌生的共享 Apple ID，否则存在设备被恶意远程锁机的严重风险！请仅在 **【App Store 个人中心】** 单独登录外区账号下载软件，下载完成后立即切换回自己的常用账号。
:::

## 四、Android 安卓端客户端选型与安装

安卓生态开放自由，所有主流客户端均可直接下载 APK 文件安装：

1. **v2rayNG**：最为稳健的通用工具，支持剪贴板快速导入节点、批量 Ping 延迟测试、支持分应用代理白名单（让国内银行、微信直连，仅浏览器出海）。
2. **FlClash (Android)**：高颜值现代界面，支持直接导入 Clash 订阅，支持策略组可视化切换。
3. **安全提示**：请务必前往官方 GitHub 项目仓库下载 APK，坚决不要在第三方不知名应用商店下载被恶意二次打包的修改版客户端。

## 五、OpenWrt 软路由与全屋透明代理

对于家庭拥有大量智能家电、Apple TV 电视、PS5/Switch 游戏主机的用户，在软路由上部署 **OpenClash** 是终极解决方案：

- **透明代理原理**：局域网内所有设备网关指向软路由 IP，无需任何设备单独安装翻墙客户端；
- **分流机制**：OpenClash 内部自动判断流量归属，访问国内网站走国内宽带直连，访问 Google、Netflix 自动分流走专线。

## 六、自研专属客户端 vs 通用开源客户端利弊权衡

| 对比维度 | 服务商自研专属客户端 (如飞猫云/光速云自研) | 通用开源客户端 (Clash / 小火箭 / v2rayN) |
|:---|:---|:---|
| **上手门槛** | 极低，下载登录即用，免配置 | 需要学习导入订阅、分流规则与内核概念 |
| **多品牌兼容** | 只能连接该特定品牌节点 | 可以同时导入多个不同机场的订阅进行备用 |
| **规则定制自由度** | 固定分流，不可修改规则 | 支持自定义规则、分应用代理与进阶脚本 |
| **适用人群** | 新手小白、给长辈/朋友配置 | 极客玩家、开发者、多梯子容灾用户 |
